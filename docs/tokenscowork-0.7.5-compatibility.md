# TokensCowork 0.7.5 适配（0.3.10）

目标宿主：TokensCowork 0.7.5，DSH 0.2.1-rc.2，Cordis 4.0.5。

## 改动

- 保留原有 DSH 兼容范围，增加已验证的精确版本 0.2.1-rc.2；通过 engines.dsh 和 peerDependencies 声明。不使用版本豁免。
- 开发依赖固定到新版宿主 SDK；更新 pnpm 锁文件。
- 图片结果按槽位传入的 sessionId 读取附件，避免依赖新版已移除的全局 current 字段；保留旧宿主回退路径。

## 验证

- 新 SDK 类型检查和构建。
- 64 项自动化用例，覆盖问答确认、取消、图片上传、生成请求、视频参数和网络恢复。
- 独立浏览器使用已安装宿主的 React/Cordis，覆盖默认选择、多步确认、关闭取消、所属会话图片和下载入口。

两个包均使用当前宿主的 evaluatePluginCompatibility 检查，通过时不传任何版本豁免。

以上为隔离验证：不启动实际宿主，不读取用户模版或凭证，不调用模型或提交真实生成任务。尚未安装到用户配置、重启应用或发布 Registry。旧版兼容路径保留，本次未在旧版桌面应用上重新实测。
